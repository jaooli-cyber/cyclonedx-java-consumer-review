# Publication scope

This is publication edition 1.0.0 of external reference and review material.
It is not a distribution of the BOM Fidelity application or comparison engine.
The edition selects reference data, public source material and measured results;
operational logs, infrastructure configuration, private preparation tools and
received generator CBOMs are not included. Frozen source material is preserved
separately; a publication projection is identified as such and does not replace
the original frozen bytes or reuse their file hashes.

The standalone verifier reads files only. It checks hashes, source bindings and
consistency of selected published measurements. Passing it does not re-run the
generator, prove the semantic labels correct or constitute a security audit.
Source-based reachability is not a record of runtime execution.

All compilation and checking for this publication took place in an isolated
remote Linux laboratory. No access to the private product is needed to read or
check the published material. No endorsement by the upstream projects is implied.
